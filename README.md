# Recoto (v4) - 開発中

> [!IMPORTANT]
> **🚧 v4は現在開発中です**  
> 録音中に予約の変更等が行えるjob方式を採用した新バージョンをGo言語で開発しています

## v3をお探しの方へ

**現在利用可能な安定版は v3 です:**

- **v3ブランチ**: https://github.com/sun-yryr/Rec-adio/tree/v3
- **v3 README**: https://github.com/sun-yryr/Rec-adio/blob/v3/README.md

v3では以下の機能が利用可能です：
- Radiko, 超A&G+, 音泉, 響の録音
- キーワード録音
- 複数番組同時録音
- LINE Notify通知
- DropBox/Object Storage保存

## v4について

v4では以下の改善を予定しています：
- **言語**: Python → Go
- **録音管理**: 録音中でも予約変更可能
- **API**: gRPC/REST API提供
- **パフォーマンス**: 大幅な性能向上
- **アーキテクチャ**: イベント駆動設計

**v4は開発中のため、現在は利用できません。**  
安定版が必要な場合は [v3ブランチ](https://github.com/sun-yryr/Rec-adio/tree/v3) をご利用ください。
