# docs - Rec-adio ドキュメント

このディレクトリには、Rec-adioのドキュメントが含まれています。

## ディレクトリ構造

- **api/**: API仕様書
- **plugins/**: プラグイン開発ガイド
- **user/**: ユーザーマニュアル
- **dev/**: 開発者ガイド

## ドキュメント作成ガイドライン

- ドキュメントはMarkdown形式で作成してください
- 図表が必要な場合は、PlantUMLやMermaidを使用してください
- コード例は、実際に動作するコードを提供してください
- ユーザーマニュアルは、技術的な知識がなくても理解できるように書いてください
- 開発者ガイドは、必要な前提知識を明記してください
