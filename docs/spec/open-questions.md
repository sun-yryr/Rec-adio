# Open Questions

更新日: 2026-02-10

## 解決済み（2026-02-10）

1. スケジュール形式  
初期リリースは単発予約のみとする。

2. ダウンタイム中の予約扱い  
`catch_up_window=15m` を採用し、15分以内は即時実行・超過はスキップとする。

3. 同時録音数の既定値  
デフォルトは `worker_count=2` とする。

4. 出力形式  
初期リリースは `m4a(aac)` 固定とする。
