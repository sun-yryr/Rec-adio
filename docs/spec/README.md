# Recoto v4 仕様書駆動開発ガイド（再設計版）

更新日: 2026-02-10  
基準コミット: `8dac181`

## 目的

- 現行の `NATSイベント駆動` から、`インプロセスのメモリスケジューラー + メモリキュー + SQLite` へ設計を再定義する。
- 仕様を先に確定し、仕様に基づく実装・テスト・レビューを行える状態を作る。

## このディレクトリの使い方

1. `01-current-analysis.md` で現状とギャップを確認する  
2. `02-requirements.md` で要件を確定する  
3. `03-domain-model.md` と `04-architecture.md` で設計を固定する  
4. `05-sqlite-schema.md` と `06-api-contract.md` を実装の単位仕様として使う  
5. `07-roadmap.md` に従って段階的に実装する  
6. 重要な意思決定は `adr/` に追記する

## 仕様更新ルール

- 実装前に仕様を更新する（仕様なしの先行実装を禁止）。
- 破壊的変更は必ず ADR を追加する。
- PR では「変更した仕様ファイル」を明示する。

## 実装完了の定義（DoD）

- 対応する要件ID（FR/NFR）とテストIDがトレースできる。
- `go test ./...` が通る。
- 仕様書と実装の差分が説明できる（差分ゼロが理想）。
