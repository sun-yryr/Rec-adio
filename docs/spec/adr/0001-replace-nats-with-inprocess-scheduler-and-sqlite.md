# ADR-0001: NATS廃止とインプロセス構成への移行

- 日付: 2026-02-10
- ステータス: Accepted

## Context

- 現行は NATS を前提としたイベント駆動構成。
- ローカル常駐ツールとしては依存が重く、リリース運用コストが高い。
- ジョブ予約と再起動復元を実現するために永続化が必要。

## Decision

- NATS 依存を廃止する。
- デーモン内部に以下を実装する。
  - メモリスケジューラー
  - メモリキュー
  - ワーカープール
- 永続化ストアとして SQLite（単一ファイル）を採用する。

## Consequences

### Positive

- 外部ミドルウェア不要で配布・運用が軽くなる。
- ジョブ定義と履歴をファイルで保持できる。
- デバッグ対象が単一プロセスに集約される。

### Negative

- 将来の分散実行にそのままは拡張しづらい。
- メモリキューはプロセス障害時に消失するため、復旧ロジックが必須。
- 単一デーモン運用を前提にする必要がある。

## Rejected Alternatives

1. NATS継続 + 追加の永続化層  
ローカル用途に対し運用コストが高い

2. Redis/BullMQ系キュー  
新規外部依存が増える

3. 完全メモリのみ（SQLiteなし）  
再起動耐性を満たせない
