# internal - Rec-adio 内部パッケージ

このディレクトリには、Rec-adioの内部パッケージが含まれています。これらのパッケージは、Rec-adioの内部実装に使用され、外部からの利用は想定されていません。

## ディレクトリ構造

- **api/**: APIサーバーの実装
  - **handlers/**: APIハンドラー
  - **middleware/**: APIミドルウェア
  - **routes/**: APIルート定義
- **config/**: 設定管理
- **core/**: コアロジック
  - **recording/**: 録音管理
  - **schedule/**: スケジュール管理
  - **event/**: イベントシステム
- **db/**: データベース関連
  - **models/**: データモデル
  - **migrations/**: マイグレーション
  - **repository/**: リポジトリパターン実装
- **utils/**: ユーティリティ関数

## 実装上の注意点

- 各パッケージは単一責任の原則に従い、明確な責任を持つようにしてください
- パッケージ間の依存関係は、できるだけ少なくしてください
- 循環依存を避けるために、適切な抽象化を行ってください
- テストを書きやすくするために、依存性注入を活用してください
